# Optional reference art

Drop clean, high-contrast silhouettes here to replace the hand-authored vector
fallback. The sampler converts the brightest channel of each pixel into alpha,
so **white art on a black or transparent background** works best. Avoid grey
paper, photographs, gradients and text baked into the image.

| File | Replaces | Suggested aspect |
| --- | --- | --- |
| `jolly-roger.png` | Home straw-hat skull | 1:1 (square) |
| `luffy.png` | About Luffy figure | 0.72:1 (900 x 1250) |
| `ship.png` | Projects ship | 1.2:1 (1150 x 950) |
| `compass.png` | Skills Log Pose | 1:1 (square) |
| `poster.png` | Resume wanted poster | 0.727:1 (800 x 1100) |

Only the five names above are read. Missing files are ignored and the vector
art stays in place, so you can add them one at a time. Reload the page after
adding a file; the reference check runs once per page load.

For `poster.png`, leave the WANTED heading and the name out of the image: the
site draws those two lines over the frame. Supply the paper, rules and portrait
only.

Keep the subject centered with a little breathing room. The layout contains the
image inside the same frame as the vector version, so an unexpected aspect
ratio will letterbox rather than stretch.
